# 我的课表 V1.3

安卓离线课程表，支持在手机中导入南京农业大学教务系统导出的 Excel，并切换每日时间轴与每周总览。Android 8.0 及以上可用，无需账号或联网。

## 手机使用

1. 将新版 APK 和自己的 `.xlsx` 课表复制到手机，例如“下载”文件夹。
2. 点击 APK 安装，按系统提示允许文件管理器安装应用。全新安装先显示空白课表。
3. 打开 App，点课表页右上角“导入”，或者设置中的“从 Excel 导入课表”。
4. 点“选择 Excel 文件”，选中课表。检查预览中的课程数、教师、地点、周次与待安排课程。
5. 点“导入这份课表”，再点“确认导入”。导入会整体替换课程，原课表保存为最近一次导入前备份。
6. 在设置中指定第 1 周周一和总教学周数。Excel 不包含开学日期，因此导入不会猜测或修改此日期。
7. 课表页点“每日”查看按时间排列的当天课程，点“每周总览”查看七天课表；“放大课表”可展开查看文字并左右滑动。“今天”定位当前教学周与星期。

点课程先查看详情抽屉，再点“编辑课程”进入编辑页，右下角加号可手动添加。没有上课时间的课程位于“待安排”。设置中的“恢复导入前的课表”会恢复课程和学期设置；只保留最近一次导入前备份。

## V1.3 界面

紧凑的日/周切换、当天当前/下一节摘要、稳定课程配色、固定星期与节次轴、完整课程详情抽屉，跟随系统深色模式。周切换与日/周切换使用短时原生过渡，系统关闭动画时也会关闭这些过渡；导入与保存结果提供反馈。

课程颜色按课程代码稳定分配，不因数据库 ID 或重新导入变化。放大周课表可横向滚动，字号较大时默认放大；点击课程可查看完整地点和备注。

V1.3 沿用本机 V1.1 签名，可直接覆盖安装并保留课程。桌面小组件尚未加入本版。

## Excel 格式

支持项目提供的 `.xlsx` 网格课表格式：周一到周日，节次网格，课程名与课程代码，教师，地点，`1-5,7-8周[30304节]` 这类周次/节次编码，以及备注中的额外安排与待安排课程。不支持旧二进制 `.xls`、截图、任意自制表格或加密文件。内容不完整或无法识别时阻止导入，保持原数据。

示例的正确结果：15 门课程、15 条安排、3 门待安排；网络安全第 6 周在周六第 3–4 节，其他相关周次在周三；图形学的两组教室均保留，形势与政策教师包含张晓敏和施晓琳。

导入保留学校文件中原有的时间重叠，周总览分栏显示；手动编辑保存仍会检查冲突。

## 数据与安装

课程和设置保存在本机 Room 数据库。正常重启保留，卸载会清除应用数据。更新同签名安装包时保留旧数据库，新安装为空白。

此包使用本机 Debug 签名，供个人安装。项目原 1.0 的签名密钥没有随源码提供；如果手机已装原 1.0 且提示签名不一致，不能直接覆盖，请先保留需要的课程资料，再卸载旧版安装新版。不要为解决签名冲突直接清除仍需保留的数据。

旧版“恢复初始课表”功能保留，需要确认后才载入原始示例课程；它与“恢复导入前的课表”是不同操作。

## 构建

标准 Android Studio 工程，Java 21、Android SDK Platform 36、Build Tools 36.0.0。设置自己的 `local.properties` SDK 路径，Windows 的盘符冒号需写为 `sdk.dir=E\:/path/to/sdk`。版本固定在 `gradle/libs.versions.toml`，最低 API26、目标 API36。

```powershell
.\gradlew.bat :app:testDebugUnitTest :app:lintDebug :app:assembleDebug
.\gradlew.bat :app:connectedDebugAndroidTest
```

本机也可运行 `build-windows.ps1`，其中 Java 和 SDK 路径需按本机安装位置调整。APK 默认输出 `app/build/outputs/apk/debug/app-debug.apk`。
